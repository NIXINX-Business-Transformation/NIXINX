# NIXINX Corporate PWA v0.1

Corporate Next.js PWA for **nixinx.com**. English-first, responsive, web manifest and installable SVG icon.

## Architectural boundaries
- nixinx.com = public commercial website; nixinx.app = client software; nixinx.site = future private MI portal; nixinx.org = NIXINX internal organization.
- Six components: Infrastructure & Integrations; NIXINX Software; Control; Engine; Management Information; Performance Management.
- Batch ingestion and customer-owned data are independent from MI licence entitlement. This corporate site is not the Engine, Control backend, or a secure MI portal.
- No unlimited implementation scope, guaranteed platform commission or exaggerated physical networking claims in subscription marketing.

## Run
`npm install && npm run dev` then `npm run build`.

## Deployment
Create a new preview Vercel project for this repository. **Do not reassign nixinx.com, bt.nixinx.com or *.nixinx.site without approval.** Email CTA uses contact@nixinx.com as an illustrative intake address, verify before launch. PWA manifest is installable where supported; offline caching is not implemented.

## Commercial framework
Implementations are one-time scoped projects; recurring managed intelligence is contracted by scope; specialized advisory is separate. Third-party referrals (Owner.com, POS etc.) generate commissions only where agreements exist. Customer funds its own data storage and processing. Track internal Canvas and SWOT separately from public copy.
